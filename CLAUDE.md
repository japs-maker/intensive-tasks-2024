# Правила проекта

## Язык
- Отвечай на русском.
- Комментарии в коде — на русском.
- Коммит-сообщения и названия переменных/функций/классов — на английском.

## Стек
- Java 21 (toolchain), Gradle
- Тесты: JUnit 5 (Jupiter)
- Статический анализ: Checkstyle (конфиг `config/checkstyle/checkstyle_sun.xml`)

## О репозитории
- Учебный репозиторий интенсива: 5 глав, 20 задач, каждая в своём пакете
  `src/main/java/com/walking/intensive/...`.
- Каждая задача — реализация метода(ов) в классе `TaskN`, условие — в самом классе.
- Тесты к задачам лежат в `src/test/java/com/walking/intensive/...`.

## Команды
- Тесты: `./gradlew test`
- Тесты для одного класса: `./gradlew test --tests "com.walking.intensive.<chapter>.<TaskName>Test"`
- Checkstyle: `./gradlew checkstyleMain`

## Соглашения по коду
- Выравнивание/форматирование стандартное для IDEA.
- camelCase для переменных и методов, классы — с большой буквы, пакеты — с маленькой.
- Имена без транслита, информативные (короткие имена — только для счётчиков циклов или где оправдано темой задачи).
- Методы называть с глагола (`getSum()`, `calculateExpression()`), boolean — с `is` (`isLeapYear()`).
- Фигурные скобки у `if`/`else` и циклов — всегда, даже для однострочного тела.
- В коммите с решением задачи менять только один класс (кроме задачи 19).
